# Liderdent

Сайт стоматологической клиники **ЛидерДент** (Красноярск): WordPress-тема `dental`, услуги, врачи, цены и заявки.

**Live:** [liderdent24.ru](https://liderdent24.ru)

## Что это

Продакшен-сайт клиники на кастомной теме WordPress:

- Главная, услуги и посадочные страниц услуг
- Врачи / специалисты, акции, ДМС, прайс, контакты и юридическая информация
- Адаптивная вёрстка, типографика Raleway, формы записи
- SEO-страницы и контентная структура под локальный поиск
- CI-деплой только кастомного кода темы (ядро WP и плагины — вне витрины)

## Стек

| Слой | Выбор |
|------|--------|
| CMS | WordPress |
| Тема | PHP, кастомная `dental` |
| Frontend | CSS / JS, шрифты Raleway |
| Ops | CI deploy (rsync темы) + smoke |

## Роль

Разработка и сопровождение темы, SEO-структура страниц, деплой кастомного кода.
